# JSON Schemas

Generated by `bun run schema:gen`; never edit by hand.

| file | points at |
|---|---|
| `schema/v1/deploy.schema.json` | `deploy.yml` v1 |
| `schema/v1/accessory.schema.json` | `accessory.yml` v1 |
| `schema/v1/group.schema.json` | `group.yml` v1 |
| `schema/v2/deploy.schema.json` | `deploy.yml` v2 (dotted names, wider charset) |
| `schema/v2/accessory.schema.json` | `accessory.yml` v2 |
| `schema/v2/group.schema.json` | `group.yml` v2 |
| `schema/deploy.schema.json` | stable alias of v1 deploy (existing examples) |
| `schema/group.schema.json` | stable alias of v1 group (existing examples) |

Add the matching line to a file:

```yaml
# yaml-language-server: $schema=./schema/v1/deploy.schema.json
```

New files declare the version they use and point at that version's schema:
`version: 1` → `schema/v1/…`, `version: 2` → `schema/v2/…`. Both versions are
generated from the registry; `src/schema.test.ts` fails when any registered
version's checked-in schema drifts.

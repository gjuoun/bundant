# JSON Schemas

Generated by `bun run schema:gen`; never edit by hand.

| file | points at |
|---|---|
| `schema/v2/deploy.schema.json` | `deploy.yml` v2 (dotted names, wider charset) |
| `schema/v2/accessory.schema.json` | `accessory.yml` v2 |
| `schema/v2/group.schema.json` | `group.yml` v2 |
| `schema/deploy.schema.json` | stable alias of the current deploy schema |
| `schema/group.schema.json` | stable alias of the current group schema |

Add the matching line to a file:

```yaml
# yaml-language-server: $schema=./schema/v2/deploy.schema.json
```

Every file declares `version: 2`. The schemas are generated from the registry;
`src/schema.test.ts` fails when a checked-in schema drifts.
